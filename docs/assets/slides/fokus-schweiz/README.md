## How to Replace a Company Logo
1. Download or export the company logo as a pure-vector **`.svg`** file (prefer a transparent background and ensure the root `<svg>` defines a tightly cropped `viewBox="..."`, not only `width`/`height`, so browser `<image>` scaling never crops; `preserveAspectRatio` automatically aligns wide or square SVGs cleanly against the Swiss map leader lines).
2. Name the file **exactly** as listed in the table above.
3. Drag it into this folder and confirm **"Replace existing file"**.
