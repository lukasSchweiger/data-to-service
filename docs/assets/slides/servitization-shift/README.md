## How to Replace an Icon
1. Export your new graphic from Canva (or vector tool) as an **`.svg`** with a transparent background and square aspect ratio (`1:1`).
2. Name the file **exactly** as shown in the table above (`wir-verkaufen-produkte.svg` or `wir-verkaufen-leistung.svg`).
3. Drag it into this folder and confirm **"Replace existing file"**.
4. Note: Because these icons render inside the slide diagram's circular frames (`#f7f2e2` fill), transparent SVG backgrounds integrate seamlessly.
